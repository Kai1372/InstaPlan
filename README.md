# InstaPlan

InstaPlan is a prototype application that allows users to search for, discover, and receive recommendations for complete holiday packages. It enables users to fully customize the app’s recommendations to find the best prices.

## Goal of the project
The goal of this project was to learn .NET MAUI and to design and implement UI mockups.

## End Results
I’m happy to say that the mockups turned out well and were successfully implemented using .NET MAUI. Feel free to take a look for yourself.
